# HGhub

**基于 Rust 与 Tauri 2 的免费纯净短剧客户端（Android 增强版 v1.2.2 · 免登录 / 无广告 / 无内购）。**

## Android 纯净增强版特性

- **免费无广、免登录即看**：已彻底移除所有账号注册、登录弹窗与服务端账号接口，零广告、零内购；收藏、点赞、关注与观看历史全部本地持久保存。
- **开箱直连 + VPN/免梯全兼容**：
  - 已适配上游最新直连 REST 接口（修复原 `/api/edge/request` 停用导致进不去的问题）；
  - 全面兼容安卓各类 VPN TUN FakeIP 网段（含 sing-box / v2rayNG / Nekobox `172.19.x.x`、Clash `198.18.x.x` 等）；
  - 内置免梯直连镜像与自动故障转移，开关 VPN 均可自动优选最快可用线路。
- **沉浸式竖屏刷剧流**：支持首页无限推荐流、题材分类、三大榜单（热门/推荐/潜力）、搜索、吃瓜社区图文与视频帖、选集与历史续播。
- **Android 原生横竖屏智能切换 & 沉浸系统栏**：
  - 横屏视频支持一键「横屏全屏」，通过 JNI 调用 Android 原生屏幕方向旋转（`SENSOR_LANDSCAPE`）并隐藏系统状态栏/导航栏；
  - 支持手机物理横置自动全屏、竖回自动退出，独立固定舞台层渲染不跑偏、不闪封面；
  - 完整适配 Android 15/16 Edge-to-Edge 挖孔屏/状态栏与手势/三键导航栏安全区高度，刷剧期间保持屏幕常亮且免手势自动连播。
- **丰富触控手势**：
  - **双指自由缩放与平移**：竖屏观看横屏视频可自由无级缩放，并提供「放大铺满 / 完整适应 / 还原缩放」胶囊按钮；
  - **单击清屏 / 双击暂停**：单击屏幕隐藏所有控件与遮罩纯享画面，双击屏幕暂停/播放；
  - **长按 2.0x 倍速 + 上滑锁定**：长按画面开启 2.0x 倍速，上滑即可锁定倍速；
  - **左右横滑预览定位** 与 **安卓系统返回手势分级拦截**（全屏 → 抽屉/锁屏 → 清屏 → 页面栈 → 首页）。
- **HLS 播放稳定性加固 & 多线路镜像测速**：内置 AES Key 与分片内存缓存、CORS 预检加速、拖动进度条防卡死自愈重连、全屏旋转过渡保活与一键镜像延迟测速切换。

### 安卓安装包选择（Releases）

- **`HGhub_1.2.2_arm64.apk`**（推荐）：适用于绝大多数主流 64 位安卓手机与平板（`arm64-v8a`）。
- **`HGhub_1.2.2_arm.apk`**：适用于旧款 32 位安卓设备或电视盒子（`armeabi-v7a`）。
- **`HGhub_1.2.2_x86_64.apk`**：适用于电脑安卓模拟器 / Chromebook（`x86_64`）。

## 本地开发

基础环境：Node.js 22、pnpm 10、Rust 1.90 或更高版本，以及目标平台所需的 Tauri 开发环境。

```bash
pnpm install --frozen-lockfile
pnpm dev             # 前端开发
pnpm app:dev         # 桌面应用开发
pnpm build           # 类型检查与前端构建
```

各平台配置位于 `src-tauri/tauri*.conf.json`。移动端及 macOS 开发需要相应平台的 SDK 和工具链。

- exFAT 等不支持符号链接的文件系统需保留 `.npmrc` 中的 `node-linker=hoisted`；部分原生构建步骤仍可能受文件系统限制。
- 依赖安装脚本的允许列表见 `package.json` 与 `pnpm-workspace.yaml`。
- 内容处理、网络安全边界与本地回归说明见[客户端内容与网络安全](docs/security.md)。
